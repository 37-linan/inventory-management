## 修复：套装加码后仍分两行（归组键 = 商品名称）

**现象**：用户在商品信息表给 Whoo 水妍两件套点「＋ 加码」，两个编码仍显示两行，
每行徽章都是「套装 · 1 个编码」。

**根因**（两条叠加）：
1. 归组键读的是 DB 里的 `set_name` 字段。这条数据是**早期手填套装名时代留下的错别字**
   ——250 号那条 set_name = 「Whoo水**姸**两件套」，另一条 = 「Whoo水**妍**两件套」，差一个字
   → 按 set_name 归组 = 两套（前端两行、**后端利润也算两倍**，是笔糊涂账）
2. 「＋加码」只改了被并入的那一条，**没有修 leaders 自己那条的旧 set_name** → 怎么加都还是两行

**改法（根因，不是补丁）**：
- 前后端统一 **归组键 = 商品名称**：新增 `setKeyOfProduct(p)`（后端）/ `_setKeyOf(p)`（前端），
  ❌ 不再读 `set_name` 字段做归组；`loadSetNameMap` / `/inventory` / `_buildDisplayRows` 全部改用它
- `ensureSetColumns` 建列后顺手 **归一化历史数据**：
  `UPDATE main_products SET set_name = btrim(name) WHERE ...`（幂等，进程内只跑一次）
- `syncSetNameRename` → `syncSetMembersRename`：**name + set_name 一起改**（只改 set_name 不够了）
- 「＋加码」并入**已存在**编码时：把它的**名称改成该套的名称**（不然合不到一行）+
  带 `sync_rename:false`（避免把它原先同名的那批商品一起拖进来）

**验证**：
- 4 组无人值守自检 **125 项全绿**：`set-bundle-test.js`(23，新增"set_name 有错别字仍算一套"场景)、
  `set-name-auto-test.js`(20，重写：归一化 + 整套改名 + sync_rename:false)、
  `product-set-row-test.js`(47)、`frontend-set-test.js`(35)
- **拉线上真实数据**跑 `_buildDisplayRows`（`.workbuddy/tmp/real-data-row-check.js`）：
  两个编码确认合成 1 行、set_name 与名称全部一致
- 线上：pm2 online、3 个文件 md5 与本地一致、SW **v38**、4 个接口 200；Git `1ab2c18` 已推

**踩坑**：`set_name` 这种"冗余副本"字段一旦被当成归组键，历史脏数据就会静默算错钱。
教训：**归组键取权威字段（名称），副本字段只用来展示，并在建列时归一化**。

## 优化：套装行只显示一个「整套」行情图

**需求**（原话）："没有必要出现了，因为我是填一套的价格不用分开来出现行情图"
—— 用户截图圈出套装行里 8809949537514 那个多余的行情图（两行「暂无价格数据」）。

**改法**：
- `products.js`：套装行的「实时行情图」列改成**只有一个**容器 `chart-{system}-set-{rowId}`（标「整套」），
  成员编码不再各生成一个；渲染循环先收集成员 id 跳过单品循环，再单独跑整套图
- `chart.js`：
  - 新增 `fetchSetHistory(members)` —— 把同一套各编码的行情**按日期合并成一条**
    （同一天取第一个非空价；某个编码接口失败只丢它自己的数据，不影响整行）
  - 新增 `renderSet(canvasId, members)`（小图 7 天）、`showLargeSet(system, members)`（放大 15 天）
  - 抽出 `_fmtLocalDate` / `_seriesFromHistory` / `_buildLargeSvg` / `_largeHtml`，单品与整套共用
    （顺手删掉了 `showLarge` 里重复的一份折线绘制代码）
  - 放大弹窗里改某天价 → `_savePriceEdit` 按 `_editMembers` **整套一起写**（保证"一套一个价"）；
    单品路径不变，只写自己
- `products.js` 新增 `showSetChart(system,rowId)`：点整套图 → `showLargeSet`（复用 `_rowRefs` 取成员）
- SW 缓存 v39

**验证**（5 组自检共 **165 项全绿**）：
