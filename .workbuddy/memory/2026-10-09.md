# 2026-10-09

## 手机版「主产品信息表」顶部按钮排 → 改成整排横向滑动（已上线）

- **现象**（用户截图）：手机上看主产品信息表，顶部那排 `➕添加物品 / 📥批量导入 / 📊导入行情 / 📑管理类型` 最后一个「管理类型」被切掉，只露出「管」，后面的字看不见。
- **根因**：`public/css/style.css` 手机端媒体查询里 `.card-header .btn-group .btn { flex: 1 }`（= `1 1 0%`）。
  外层 `.card { overflow: hidden }`，而 flex item 的 `min-width:auto` 会让按钮**不肯缩到内容宽度以下**，
  4 个按钮实宽 4×~106 + 3×8 ≈ 448px > 可用 ~329px → 整排溢出被卡片裁掉。
  ❗**不是「文字换行不了」那么简单**：`flex:1` 根本没把它们压小，是整排溢出被裁。
- **改法**（只动 `@media (max-width: 768px)` 内，**电脑版零影响**）：
  - `.btn-group` 加 `overflow-x: auto; overflow-y: hidden; -webkit-overflow-scrolling: touch; scrollbar-width: thin; padding-bottom: 4px;`
  - 加 `::-webkit-scrollbar { height:5px }` / `-track` / `-thumb`（Chrome/安卓可见细滑轨；iOS 用系统浮层滚动条）
  - `.btn` 由 `flex: 1` → **`flex: 1 0 auto`**：够宽时平分撑满，不够宽时保持文字完整宽度、整排可滑
- `public/sw.js`：`CACHE_NAME` v56 → **v57**（`style.css` 在 SW 预缓存清单第 5 行）
- **验证**：花括号平衡 0/最大嵌套 2；线上 md5 与本地一致（`style.css c7430125…`、`sw.js 5c7954e0…`）；
  首页 200 / css 200 / 线上 sw 已是 v57 / 线上 CSS 含 `flex: 1 0 auto`；
  `tmp/` 29 个 `*test*.js` 全量重跑全绿（纯 CSS 改动，未触碰 JS）。
- 交付对比页：`.workbuddy/tmp/preview-btn-group.html`（左右两个 393px 手机屏，修复前 vs 修复后）。
- ⚠️ 惯例提醒：`.card-header .btn-group` **全站只有主产品信息表这一处**（已 grep 确认），所以改成全局手机端规则是安全的。
