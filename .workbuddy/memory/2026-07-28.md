# 2026-07-28 工作日志

## 稳定性改造 - 手机端访问与服务器崩溃保护

### 背景
用户反馈手机端无法访问，要求提升系统稳定性。

### 改造内容

#### 1. server.js - 崩溃保护增强
- 添加 `process.on('uncaughtException')` 全局异常捕获 — 任何未捕获错误不会导致服务器退出
- 添加 `process.on('unhandledRejection')` 全局Promise拒绝捕获
- 添加文件日志系统（logs/server.log），按时间戳记录所有启动信息和错误
- 添加 `getLocalIP()` 函数从系统网络接口自动获取本机局域网IP
- 启动时在控制台和日志中显示完整访问地址（电脑端+手机端IP+主机名）
- 添加 `/api/health` 健康检查接口（含uptime），放路由最前面避免被通配拦截

#### 2. start.bat - 完全重写
- 不再使用 `taskkill /F /IM node.exe` 杀死所有node进程，改用端口检测
- 使用 `start /MIN` 后台启动，关闭窗口不影响服务运行
- 自动检测并显示本机局域网IP地址
- 自动检查启动是否成功
- ��持运行时再次启动（检测到已在运行则跳到IP显示）

#### 3. 新增辅助脚本
- `stop.bat` — 按端口3000精确停止服务，不会误杀其他node进程
- `restart.bat` — 一键重启
- `status.bat` — 查看服务运行状态、PID、内存占用、IP地址
- `install-startup.vbs` — 开机自启动安装（添加到Windows启动文件夹）
- `remove-startup.vbs` — 取消开机自启动

#### 4. PWA更新
- 缓存版本从 v1 升级到 v2，强制手机端重新加载最新资源
