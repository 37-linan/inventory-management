## 环境坑（新踩）
- `ssh 远端 "export PATH=...\$PATH; ..."` 里的 `$PATH` 被**本地** shell 展开 → 把 Windows PATH（含 `/c/Program Files (x86)/...`）塞进远端命令 → 远端 `syntax error near unexpected token '('`。
  以后远端命令用单引号包，或直接 `curl` 公网文件对 `md5sum`（本次就是这么验的，够用）

## 入库记录表「筛选条件」支持多选
- 用户：「这个可以多选筛选条件吗」（截图 = 入库记录表筛选面板里那排字段胶囊）
- 原为单选：`_inboundFilter = {field:'all', keyword}` —— 点了「物品编码」就只能在这一个字段里搜
- 改为多选：`{fields:[], keyword, exact}`；`fields` 空 = 全字段；**多字段是 OR（任一命中即显示）**
  - `_setInboundFilterField` → `_toggleInboundFilterField`（再点一次 = 取消；点「全部字段」= 清空）
  - 单字段且是枚举型（渠道 / 标记 / 设备）→ 仍给下拉；**多选或全字段 → 文本框**（下拉 change 带 `exact=true` → 精确匹配）
  - 切换字段时**文本字段之间保留关键词**（方便「先输词、再勾字段」），只有涉及下拉才清空
  - 胶囊加 hover 提示；hint 列出当前选中的字段名；面板初始文案同步改
- 自检：新增 `tmp/inbound-filter-multi-test.js`（**80 项**，拉线上真实 66 条入库 / 122 个商品）
