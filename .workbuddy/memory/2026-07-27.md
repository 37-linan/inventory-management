# 2026-07-27 工作日志

## 完成内容
- 完成了出入库库存管理工作台的完整开发
- 技术栈: Node.js 22 + Express + Node.js内置SQLite(node:sqlite) + 原生前端(HTML/CSS/JS)

## 项目结构
- server.js — Express主服务器，提供RESTful API和静态文件服务
- db/init.js — 数据库初始化（两个独立数据库：main.db和douyin.db）
- routes/main.js — 主系统API路由（CRUD产品/入库/出库/库存/配置）
- routes/douyin.js — 抖音刷券系统API路由（结构同上，数据独立）
- public/ — 前端SPA应用
  - index.html — 主入口，左侧导航栏
  - css/style.css — 响应式样式（桌面+移动端）
  - js/app.js — 主应用逻辑、路由导航
  - js/modules/api.js — API请求封装
  - js/modules/config.js — 配置管理（类型/渠道选项动态管理）
  - js/modules/barcode.js — 条码扫描模块（原生BarcodeDetector API + 手动输入）
  - js/modules/camera.js — 相机拍照模块（MediaDevices API）
  - js/modules/chart.js — 价格波形图（纯SVG绘制）
  - js/modules/products.js — 产品信息表页面
  - js/modules/transactions.js — 出入库登记/台账页面
  - js/modules/inventory.js — 库存看板页面
- public/manifest.json + sw.js — PWA支持（移动端可安装为APP）
- electron/main.js — Electron桌面端封装

## 功能要点
1. 两个独立系统：主系统和抖音刷券系统，数据完全独立
2. 主产品信息表：添加物品表单（编码/名称/规格/单位/行情/类型）、信息表格按类型分组、7天滚动价格波形图
3. 主出入库台账：入库登记（扫描编码/数量/渠道管理/拍照/订单号）、出库登记（扫描/拍照/地点）、信息台账（自动引用产品名称和规格）
4. 主库存看板：统计卡片、库存明细表格、最近出入库动态
5. 条码扫描：原生BarcodeDetector API + 手动输入双模式
6. 类型和渠道选项可动态添加管理
7. 价格每日录入，未录入自动沿用上次价格
8. PWA支持，手机上可安装为APP
