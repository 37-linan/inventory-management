# 追加：修复「设颜色导致收起的单号组全部弹开」

## 现象 / 根因
- 用户：把入库表某些单号组收起来后，一填行颜色，收起的又自动展开了
- 根因：折叠状态**只存在 DOM**（`icon.textContent` + 每行 `style.display`），
  而 `_setColor()` → `_refreshInboundTable()` → `_renderInboundRows()` 会 `tbody.innerHTML = html`
  **整块重绘**，DOM 上的 display 全丢 → 全部展开
- 同一类触发点：行内编辑保存（`_editInboundCell` commit）、删除整单、删除单条

## 修法（仅前端 `transactions.js`）
1. 模块上加 `_collapsedGroups: new Set()`，**key = 订单号**（无单号用 `（无单号）`）
   - ❌ 不能用渲染下标 `inb-grp-${gi}`，它随排序/筛选变化 → 会串组
2. `_renderInboundRows()`：`const collapsed = this._collapsedGroups.has(orderNo)`
   - 组头图标 `▾/▸` 按它渲染；明细行 style **合并**颜色与隐藏：
     `[rowColor ? '--row-bg:X;--row-bg-hover:X' : '', collapsed ? 'display:none' : ''].filter(Boolean).join(';')`
     （原来是三元拼 `--row-bg`，直接加 display 会互相覆盖）
3. `_toggleGroupRows(groupId, cacheKey)`：改完 DOM 后按 `_groupStatsCache[cacheKey][0].order_no`
   同步 Set（`collapsed` 变量是"点之前是否收起"：true=要展开→delete，false=要收起→add）
4. 出库记录表是平铺列表、**没有分组折叠** → 查证后确认无此 bug（已回复用户）
