## 出库信息单：电脑端改「选择商品」弹窗（手机端不动）

用户需求：电脑版的出库信息单，点原来的「扫码」按钮 → 弹窗列出**库里有库存的商品**，
选一个 + 填数量 → 直接出库；**手机版不要改，还是扫码**。

### 实现
- `transactions.js` 新增 `_isTouchDevice()`：UA 命中手机关键词 或 `(pointer: coarse)` → 手机
  - 特意没用项目已有的 `isMobile()`（那只是 `innerWidth<=768`，电脑窗口拖窄会误判）
  - 触摸屏笔记本主指针是鼠标 → `pointer: coarse` 为 false，不会误判 ✓
- `renderOutboundTab()` 按它二选一：手机「扫码」`triggerBarcodeScan('outbound-code')`／
  电脑「选择商品」`showOutboundPicker(system)`；订单号那行的扫码两端都保留
- 新增方法：`showOutboundPicker()` / `_renderOutboundPicker()` / `_renderPickList()` /
  `_pickSelect(i)` / `_renderPickBottom()` / `_renderPickWarn()` / `_confirmOutboundPick()`
- 数据源复用现成的 `/api/{system}/inventory`（含 stock），按 code 合并（同编码多条 → 库存相加），
  库存降序；默认只显示 stock>0，可勾「只看有库存」
- ⚠️ 两个防坑：搜索框输入时**只重绘 tbody**（重绘整个弹窗会失焦）；点行选中**只改高亮不重建表**
- 提交走**原有** `submitOutbound()`：先把 code/qty 回填到 `#outbound-code` `#outbound-qty`，
  这样表单里的地点/订单号/图片自动带上，出库逻辑零重复
- 数量超库存只提示不拦截（用户可能要补录历史出库）
- SW v26 → **v27**；Git `a1e7d07` 已推 main
